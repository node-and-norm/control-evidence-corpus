# Course-alignment supplement 0.3.1

Read [From the course to the study](COURSE_ALIGNMENT.md) for the source-derived observations, proposed five-chapter reading path, and research-specific safeguards. The [source register](source-register.json) pins the five inspected Studio modules to one course commit and deduplicates the six uploaded copies of the slide deck. Review coverage and access limits are explicit.

The [repository notebook](course-plan.ipynb) is a small executable reading index. It uses the checked-out source-register file. Expanded, self-contained HTML and notebook editions and their generator are supplied in the conversation's downloadable supplement package; no live website is deployed here.

This supplement does not replace evidence workbench 0.3.0, freeze pilot protocol 0.2.0, add LangChain dependencies, execute course code, or create empirical findings. The five proposed study chapters are a plan; they are not five completed experiments.
